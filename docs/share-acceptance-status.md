# X 共有の追加確認と未完了項目

## この差分

- ホーム・結果で共用する共有文に `#サバサバ #ゲーム制作` を追加します。本文、実際の改行、末尾の既存ゲーム URL を維持します。
- 共有時は操作の同期処理で空のウィンドウを開き、`opener=null` の読戻しを確認してから、`noreferrer`／`no-referrer` を指定した子ウィンドウ内のリンクで X に進みます。準備に失敗した場合は空ウィンドウを閉じることを試み、既存のコピー／手動選択に戻ります。ボタンの要素・disabled・キーボード操作・表示は変更せず、修飾キーによるリンク操作を新しく追加しません。
- 共有の遅延完了はモード・言語・出撃 ID・共有本文の世代と照合します。新しい画面設定は自身の pending／表示をリセットし、古い完了・finally・タイマーは更新しません。アンマウント、pagehide、非表示化でも無効化し、再表示しても古い要求を復活させません。
- 既存のブラウザ確認に、15 言語の共有文・ボタン寸法・祖先要素によるクリップ・透明／非表示・色・操作結果の確認コードを追加します。確認コードの存在は、全画面の受入完了を意味しません。
- ブラウザ確認用の通信境界は固定のローカルプレビューだけを取得し、外部アクセス・書込み・リダイレクト・WebSocket を拒否します。Google Fonts の CSS は空のローカル応答です。既存のランキング読取は、指定ホスト・RPC・POST・2 キー・通常／エンドレスの ID・整数の `p_limit=30` が完全一致する場合だけ空配列を返すローカル代替応答にします。実ランキングには接続しません。
- 素材取得コードは、通常の匿名プレイでカウントダウン後 500 ms に取得し、取得前後の `playing`、書込み 0、拒否通信 0、ランキング代替応答 0 を要求します。ゲーム時間・出現・描画をテスト都合で変更しません。

戦闘・進行・ルール・得点・専用の開始／送信 API・ランキング処理・保存処理は変更しません。`GameCanvas` の変更は共有ボタンに渡すコンテキスト情報の 2 箇所だけです。通常スコア用の 8 列応答検証を専用 API に適用していません。README、既存画像、依存ロック、Vite 設定、main の 2 ワークフローは変更しません。追加の自動実行トリガーもありません。
